# BoothLore for Windows

Public Windows installers for **BoothLore**, the photo booth app for iPad, Android tablets and Windows.

- Download the latest installer from **https://boothlore.com/downloads** or from this repository's Releases.
- Each release lists its SHA-256 checksum. Installers are signed by **Claian LLC**.
- Windows 10 or later (x64). Setup installs the Microsoft Visual C++ runtime if needed.

This repository contains release files only. The application source is maintained separately and is not published here.
